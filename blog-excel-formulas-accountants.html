5 Excel Formulas Every Accountant Should Know

Five practical Excel formulas that help accountants clean data, match records and prepare finance reports more efficiently.

By DigiCafe Editorial Team · Updated 25 November 2026 · 6 min read

Accountants often work with large lists of bank transactions, invoices, vendor balances and payment records. Excel formulas can reduce repetitive work, but the result still needs to be checked against the source documents.

1. XLOOKUP: Find matching records

Use XLOOKUP to retrieve a value from another list, such as finding a vendor name from a vendor code or checking an invoice reference.

=XLOOKUP(A2, VendorList[Code], VendorList[Name], "Not found")

This example searches for the code in A2 and returns the corresponding vendor name. The message “Not found” makes missing matches easier to identify.

2. SUMIFS: Total amounts using conditions

SUMIFS is useful for preparing vendor-wise, month-wise or account-wise totals.

=SUMIFS($D:$D,$B:$B,G2,$C:$C,H2)

Here, column D contains amounts, column B contains vendor names and column C contains months. The formula totals amounts matching both criteria.

3. COUNTIF: Count repeated references

Use COUNTIF to identify how many times a UTR, invoice number or transaction reference appears.

=COUNTIF($A:$A,A2)

A result greater than 1 can flag a possible duplicate. It is an alert for review, not proof that a transaction is duplicated.

4. IF: Apply a simple decision rule

IF can classify a reconciliation result based on a difference column.

=IF(E2=0,"Matched","Review")

For currency calculations, use an agreed rounding tolerance where appropriate rather than relying on an unrounded floating-point comparison.

5. IFERROR: Keep reports readable

IFERROR can replace formula errors with a clear message while you investigate missing or invalid inputs.

=IFERROR(XLOOKUP(A2,Ref[ID],Ref[Amount]),"Check reference")

How to use these formulas responsibly

  • Keep an untouched copy of the original bank statement or source export.
  • Standardise dates, amounts and reference formats before matching.
  • Review duplicates, unmatched entries and exceptions manually.
  • Document the matching logic so another person can reproduce the result.
  • Reconcile totals back to the source records before sharing the report.

Practical takeaway: XLOOKUP helps retrieve data, SUMIFS totals it, COUNTIF flags repeats, IF classifies results and IFERROR makes exceptions easier to read. Together, they provide a useful foundation for everyday accounting work.
